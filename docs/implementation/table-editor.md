# Table Editor

Spec: `S12`
ToDo: `Phase C1`

## Goal

Create persisted table definitions whose preview and batch exports are generated by one
Qt-independent table runner.

## Inspect first

- `src/flowdesk_core/statistics.py`, `export.py`, `execution_report.py`, `models.py`
- `src/flowdesk_cli/run_project.py`
- `src/flowdesk_storage/project.py`
- `src/flowdesk_qt/main_window.py`, `population_tree.py`
- export/statistics tests

Prerequisites: persistent statistics and groups. Read `statistics-definitions.md` and
`export-and-cli.md`.

## Model contract

`TableDefinitionSpec` has ID/name, row iterator, columns, filters, sort, and display
formatting. `TableColumnSpec` source is one of keyword, StatisticSpec, platform result,
safe formula, or constant. Core values and display formatting remain separate.

## Increments

1. Add definition/result row types and schema round-trip.
2. Implement keyword and statistic columns for explicit sample iteration.
3. Add group/population-path iteration and deterministic row order.
4. Add safe formula dependency ordering; reject cycles and arbitrary Python.
5. Add filters/sort and undefined/error propagation.
6. Build Qt editor for column add/reorder/rename/hide/format and preview.
7. Export CSV/TSV plus provenance sidecar; add optional XLSX only in a separate increment.

## Required tests

- Hand-built table has exact rows, typed values, and deterministic order.
- Missing sample/statistic/keyword produces configured status, not a shifted column.
- Formula cycle and unsafe expression are rejected.
- Hidden/conditional formatting does not change exported numeric value.
- GUI preview equals CLI batch output after project reload.

## Do not do

- Do not read values back from Qt table cells for export.
- Do not format numbers before formula evaluation.
- Do not make XLSX a mandatory dependency.
