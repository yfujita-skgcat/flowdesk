# 並列化

- GUI画面でのサンプル切替時の描画のための計算、run pipeline の計算について並列化が可能かどうか検討して、可能であれば方法、計画を提示してください。
- サンプル切替時の描画のための計算では例えば、ドット集団を n 個のグループに分けて、各グループを別スレッドで計算するなどの方法が考えられます。
- run pipeline の計算についても、各サンプルは互いに独立しているので独立して並列化することが可能なように思います。overlay の実装には注意が必要かもしれないが、可能であれば、方法、計画を提示してください。
- batch export についても、各サンプルごとに独立して処理できるため、並列化が可能なように思います。各サンプルのエクスポート処理を別スレッドまたはプロセスで実行することで、全体の処理時間を短縮できないか検討して、かのうであれば、方法、計画を提示してください。

# その他
- Batch export は時間がかかるのだけど、途中経過がどこにも表示されないので、進捗状況を表示する方法を検討してください。例えば、各サンプルのエクスポート処理が完了するたびに進捗バーを更新するなどの方法が考えられます。もしくはメッセージを下のメッセージが出る所に表示するなどの方法も考えられます。
