# Scientific Review Skill

Use this skill when reviewing analysis correctness.

- Call out assumptions that may be questionable for flow cytometry.
- Document uncertainty in compensation, transform, gate, or frequency behavior.
- Prefer tests or xfail placeholders over silent assumptions.
- Confirm GUI and headless execution use the same analysis definitions.
- Treat reproducibility regressions as high priority.
